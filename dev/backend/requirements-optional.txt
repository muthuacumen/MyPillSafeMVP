# Optional heavy dependencies (CB4 Claude voice, assistant STT).
# Installed by render.yaml and the Docker backend image; not folded into
# requirements.txt itself since it's still useful to be able to run the core
# app without these heavier packages.
# Install with: pip install -r requirements-optional.txt
#
# Each capability degrades gracefully without its package — the relevant
# endpoint returns a clear error/fallback instead of crashing — so the core
# app works fully without any of these.
#
# Prescription OCR (Priority 1B) moved OFF this list entirely (Task A4,
# deploy-readiness build): PaddleOCR/PaddlePaddle no longer run in this
# backend at all -- `app/services/ocr_service.py` is now a thin httpx client
# that POSTs the uploaded image to the `dev/brains` sidecar's
# `/ocr/prescription` endpoint (see that module's docstring). That removed
# ~3 GB from this image and a ~1.5 GB RAM spike per scan (measured ~2m21s
# CPU per label on the old in-process CPU engine). `pillow` and `numpy` were
# ONLY pulled in for that PaddleOCR path -- grepped `app/` for `PIL`/
# `numpy`/`cv2` imports before removing them and found none, so both are
# gone too, not just paddleocr/paddlepaddle.
